# TailYew App (Scaffolded)

You’re inside the app generated by `create-tailyew-app`. Use the Makefile to build and run the frontend with Trunk.

## Prerequisites
- Rust toolchain with `wasm32-unknown-unknown` target (`rustup target add wasm32-unknown-unknown`)
- Trunk (`cargo install trunk`)
- Node/npm for Tailwind CLI (`npm install` in this folder)

## Run the app
```sh
npm install
make run-frontend    # starts Trunk dev server on http://localhost:9001
```

## Keeping the TailYew safelist up to date
If you update the TailYew crate and need the latest CSS safelist, pull it into this project with:
- From this folder: `make copy-tailyew-safelist`
- From the app root: `make fe-copy-tailyew-safelist`

## Project layout (frontend/)
- `src/` – Yew app code (pages, templates)
- `static/` – static assets (manifest, service worker, images, pkg/)
- `index.html` – Trunk entrypoint
- `Trunk.toml` – Trunk config
- `main.css`, `tailwind.config.js` – Tailwind setup
- `Makefile` – build/run targets
